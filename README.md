# Tensor

`Tensor` provides Silex's multidimensional numerical foundation. One immutable
public value covers `float32` and eight integer dtypes, explicit CPU/GPU
placement, lossless transfers, and ordered `float32` scalar compute. Automatic
differentiation and neural-network packages can build on this contract without
belonging to the core.

```text
silex install Tensor
```
